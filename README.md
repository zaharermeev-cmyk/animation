# Veil Background — прототип

Анимированный фон: перспективная сетка-«тоннель» из плиток, шёлковые вуали из нитей, сходящиеся к центру, и искры на нитях. Есть светлая и тёмная темы.

Запуск: `python3 -m http.server` → http://localhost:8000

## Интро
Пустой экран → от центра материализуются плитки (со светящимся фронтом) → из центра вырастают вуали → появляются искры.
Тайминги — `intro` в `DEFAULTS` (`src/veil-background.js`). `bg.replay()` проигрывает интро заново.

## Текст на плитках
```js
bg.pin(el, { col: 8, row: 3, cols: 9, rows: 3 }); // конкретные плитки
bg.pinArea(el, 0.17, 0.1, 0.23);                  // x, y, ширина в долях экрана
```
Элемент натягивается на плитки в той же перспективе и появляется вместе с ними.

## Тема
Цвета задаются в `src/veil.css` через переменные `--veil-*`. Тема переключается атрибутом `data-theme="light|dark"` на `<html>`.
