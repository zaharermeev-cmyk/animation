# Veil Background — прототип

Анимированный фон: 3D-тоннель из плиток (пол уходит к горизонту и загибается в стены и потолок), объёмные вуали из сотен нитей со свечением и искрами. Есть светлая и тёмная темы.

Запуск: `python3 -m http.server` → http://localhost:8000

## Интро
Пустой экран → от центра материализуются плитки (со светящимся фронтом) → из центра вырастают вуали → появляются искры.
Тайминги — `intro` в `DEFAULTS` (`src/veil-background.js`). `bg.replay()` ## Объекты на полу
```js
bg.place(el, { col: -5, row: 0, height: 0.55 }); // плитка: col — вбок от центра, row — вглубь
bg.place(el, { x: -2, z: 3.5, height: 0.8 });    // или мировые координаты
```
Нижний центр элемента ставится на пол. Размер зависит от глубины, под объектом рисуется контактная тень. Объект проявляется вместе со своей плиткой.

появляется вместе с ними.

## Тема
Цвета задаются в `src/veil.css` через переменные `--veil-*`. Тема переключается атрибутом `data-theme="light|dark"` на `<html>`.
